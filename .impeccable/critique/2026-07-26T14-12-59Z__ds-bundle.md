## What changed in this pass

All 4 remaining lower-priority findings from the last critique are now closed, each verified independently (not just source-level):

1. **MetricCard orange/amber separation** — `orange` moved from `border-orange-200/text-orange-700` to `border-orange-300/text-orange-800`, keeping `amber` on its own `dispute-*` tokens. Verified in both source and the regenerated screenshot: the two cards ("PENDIENTES" vs. "EN DISPUTA") are now visibly distinct — one reads as deeper saturated orange, the other as a lighter muted gold.

2. **CSS custom-property fallbacks** — every `var(--token)` in Modal, DataTable, and Label now carries a fallback value (`var(--bg-card, #ffffff)`, etc.). Verified: 14 occurrences across the three files, all with fallbacks, zero bare `var()` calls remain. Confirmed visually — Modal now renders a real card (background/border/radius) and Label text renders in muted gray even in the theme-less standalone preview, instead of appearing fully unstyled.

3. **Focus-visible ring runtime verification** — confirmed with a **real keyboard Tab** (not a scripted `.focus()`, which doesn't trigger `:focus-visible` in most browsers) against the live `ds-bundle` preview: `button.matches(':focus-visible')` returned `true`, and the computed `box-shadow` showed the actual painted ring (`0 0 0 1px #fff, 0 0 0 3px oklch(0.488 0.243 264.376)` — a white offset ring plus the blue-700 focus ring), matching the `focus-visible:ring-2 focus-visible:ring-blue-700 focus-visible:ring-offset-1` classes exactly. This was previously unverifiable from static screenshots alone; now confirmed live.

4. **Component documentation** — added a real usage doc (`.md`) alongside each of the 12 components' source files, picked up automatically by the design-sync doc-matching convention (no config changes needed). Each `.prompt.md` now leads with "when to use," accessibility notes, and (where relevant) variant-selection guidance and theming notes — followed by the full TypeScript prop contract, which is still auto-appended. Confirmed: `docs: 12/12 components matched` on rebuild, and spot-checked that the type block wasn't accidentally suppressed by an ambiguous "## Props" heading in one doc (fixed by renaming it to "## Sizing").
